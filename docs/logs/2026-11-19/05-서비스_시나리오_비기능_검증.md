## 2. 수정

| 발견 | 원인 | 수정 |
|---|---|---|
| 외부 API 키가 없어 하나도 판단하지 못한 응답이 "다른 원재료나 약정 조건을 알려 주시면 다시 계산하겠습니다" 라고 조건 변경을 요청함 | 충족 항목이 없을 때의 안내를 판단 불가와 요건 미달에 똑같이 붙임 | `responder.py`: 재시도해도 같은 실패(`INVALID_KEY`, `UPSTREAM_ERROR`)로 모든 항목이 판단 불가이면 조건 변경 안내를 생략. `test_server.py`에 `test_key_failure_does_not_ask_to_change_conditions` 추가 |

## 3. 확인 스크립트 작성 중 고친 기준

| 처음 기준 | 문제 | 바꾼 기준 |
|---|---|---|
| `.env`의 모든 값을 형상관리 파일과 대조 | 모델 이름, 주소 같은 비밀이 아닌 설정 값이 문서에서 걸림 | API 키 4종(`KEYS`)의 값만 대조 |
| 조문 검색 실패 이벤트가 1건 | 계획에 조문 검색이 2단계(납품대금 연동, 주요 원재료) 들어 있어 2건 실패 | 실패 이벤트의 코드가 모두 `UPSTREAM_ERROR` 인지 확인 |
| 겹침 안내 화면을 저장 직후 캡처 | 안내가 대화 영역 아래로 잘림 | 저장 결과가 나타날 때까지 기다린 뒤 결과 영역으로 스크롤 |
