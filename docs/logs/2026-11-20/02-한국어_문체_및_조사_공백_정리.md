# 한국어 문체 및 조사 공백 정리

- 작업일: 2026-11-20
- 범위: 파이썬 주석과 docstring의 문체 수정. 영어 단어, 숫자와 한국어 조사 사이의 공백 제거는 `backend/` 파이썬 파일 46개 전체(문자열 리터럴, LLM 프롬프트 포함), `docs/*.md`, `frontend/js`에 적용
- 결과: `unittest` 105/105 OK. `compileall` 통과. 프론트엔드는 브라우저에서 확인하지 않음.

## 1. 수정

| 발견 | 원인 | 수정 |
|---|---|---|
| 영어 단어와 한국어 조사 사이에 공백이 있음 (`Tool 을`, `Agent 가`, `LLM 이`) | 같은 파일 안에서도 `Worker가`와 `Worker 가`가 섞여 있음 | `tokenize`(주석)와 `ast`(docstring)로 대상 줄만 골라 영어 단어 뒤의 조사 공백을 제거. 124줄. `Tool 이름별로`처럼 조사가 아닌 단어는 조사 뒤에 다른 글자가 이어지는지로 구분해 제외 |
| 함수 docstring과 주석이 명사구로 끝남 (`... 작업 목록`, `... 또는 None`, `1) LLM 초안 검증`) | 요약 문구로 작성 | `graph.py`, `planner.py`, `state.py`, `ecos.py` 등 27곳을 서술어로 끝나는 문장으로 수정. 반환값 설명은 "반환한다"로 명시 |

## 2. 추가 수정

| 발견 | 원인 | 수정 |
|---|---|---|
| 숫자 뒤 조사 공백(`401 을`, `10 으로`)과 문자열 리터럴(LLM 프롬프트, 응답 문구, 확인 스크립트 라벨, 테스트)의 `Tool 이라 뺐습니다.` 같은 공백이 남음 | 1차 작업이 영어 단어 뒤의 주석과 docstring만 대상으로 함 | 한글 조사는 코드 부분에 나올 수 없으므로 파이썬 파일 전체에 적용. 110곳에 더해 `로만`, `에서는` 같은 결합형 조사도 처리. 조사 뒤에 다른 글자가 이어지는 단어(`이름`, `이상`)는 제외 |
| `docs/*.md`와 `frontend/`(`js`)에도 같은 공백이 남음 | 2차 작업이 파이썬 파일만 대상으로 함 | 같은 규칙을 적용. `docs` 7개 파일 23곳, `frontend/js` 5개 파일 15곳 |
